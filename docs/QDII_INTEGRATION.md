# QDII 接入说明

核验日期：2026-10-12，北京时间。

## 范围与口径
- 用户指定唯一业务数据源为 FEIXIA：https://feixia.org/ ，不逐只查基金公司公告，不展示官网公告链接。
- 接入的是源站公开首页中列出的基金，不宣称覆盖全市场全部 QDII。
- 首次真实采集：43 个份额，22 个展示组；20 个限额可申购份额，23 个暂停份额；对应 10 个可申购基金组、12 个暂停基金组。额度合计与源站首页一致。
- 每个代码为一个份额，A/C 通过 data/qdii_groups.json 明确配对；新增未知代码独立展示，不按名称猜测配对。
- A/C 额度或申购状态分别保留；暂停不填写假定金额，金额为 null。源站可申购表中 0 元或“不限购”表示不限购，不能当作暂停。
- “份额额度合计”按源站有限额度相加，不表示投资者实际可买入总额，也不假定不同份额或不同销售渠道额度可独立累加。
- 源站首页只提供“几小时前”等提示，source_updated_at 保持 null；fetched_at 是实际抓取时间，数据文件保留原始提示，不伪造精确源站更新时间。

## 获取与更新
- scripts/update_qdii.py 每次仅读取一次公开首页，不登录、不访问关注、管理或私有端点。robots.txt 允许公开首页抓取；这不等于网站授予再分发许可。首页有版权标记，未发现明确再分发许可证，按用户指定的数据源接入，不宣称取得第三方授权。
- 独立 GitHub Actions 全天每小时第 37 分钟启动，包括夜间和周末，不依赖 NYSE 交易日。2026-10-15 按用户要求取消静默窗口；GitHub 定时可能延迟，网站在采集、校验和部署完成后刷新。
- 手动 Run workflow 可主动检查；命令行 --gate-only、--force 保留兼容，自动与人工检查均不受时段限制。
- 工作流使用与纳指日报相同的 ndx5s-production 并发组，避免两次部署互相覆盖。纳指日报仍使用原有收盘后更新安排。
- 采集、校验失败时不替换 data/qdii.json；单独记录失败状态，网站展示上次成功数据，失败状态保存在数据文件和 Actions 日志。采集时间与失败状态保存在数据文件，页面按用户要求不展示时间和提示。
- 首次采集只建基线，不编造历史变化；以后记录实际监测到的状态和额度变化时间，不宣称是源站生效时间。

## 原指标保持
1. 价格：累计高点回撤、252 日高点、MA200 位置和 20 日斜率；-5/-10/-20% 阈值。
2. 宽度：SPX/NDX MA50/MA200 四项平均；70/50/30% 阈值；有效样本至少 60%；近高点宽度走弱规则保持。
3. 风险：VIX 15/20/30 阈值、5/20 日变化与冲高回落。
4. 资金价格：10Y 实际利率、5/20 日 bp 变化、MA20/MA60 通道。
5. 基本面：权重调和 EPS/PE、快照或分析师修正、原四类判断和覆盖条件。
- 不用 ETF 替代指数，不替换公式，不增加投资评分。

## 实施顺序
1. 保存检查与授权审计，建立公开发布白名单。未证明有再分发权的数据（含由其产生的状态与总结）在输出中移除，不仅在浏览器隐藏。
2. 独立构建器导入原 HTML JSON；原脚本继续生成内部报告，网站用外置静态 JSON 与本地 Chart.js。
3. 手机优先：五大指标切换、时间区间、图例开关、触摸查看、指标规则、桌面宽屏；显示数据日期、网站更新时间、各模块观测日期和缺失提示。页面无数据来源模块，仅保留必要署名。
4. GitHub Actions 每个工作日 UTC 22:17 运行，NYSE 日历判断交易日且已收盘，兼容夏令时、节假日和提前收盘。持续保存 EPS 快照，取数失败不覆盖上一版；禁止 demo 发布。
5. 新建独立私有 Invest 仓库及 Cloudflare Pages 项目，只用免费 pages.dev。若 invest 子域名已占用，使用 invest-daily-zhoupixue。
6. 比对原脚本哈希、报告结构、非有限数据、日期与快照、授权脱敏结果；检查手机和桌面交互；部署后核实公开输出。

## 授权限制
截至检查时没有现有数据再分发许可文件。免费获取不代表允许公开发布。Yahoo/Cboe/Slickcharts/Stooq/Nasdaq 数据及衍生指标默认暂停公开，等待许可证据；不擅自购买许可。可先上线明确显示授权待核实的交互界面。正式五模块数据上线与自动公开更新以授权证据和 CI 凭据为前提。
